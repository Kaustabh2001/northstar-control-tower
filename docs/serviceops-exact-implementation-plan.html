Human authority

Action risk tiers

The model can recommend broadly; execution authority stays narrow and explicit.

Green · low impact

Read-only lookup, known FAQ, reversible action. Auto-draft is allowed; execution still passes policy.

Amber · approval required

Account changes, uncertain diagnosis or customer-impacting updates require a named reviewer.

Red · specialist handoff

Security, privilege, destructive action and production change cannot execute autonomously.

Local-first reality

What “local” means

Jira Free is not local.
Strict-local mode uses GLPI. Jira Cloud Free is optional and cannot be used to claim an air-gapped deployment.
Local AI still has cost.
GPU/CPU time, energy, storage and operations are measured per ticket.
A2A services

Agent cards and responsibilities

Agents expose typed skills and return artifacts. They do not receive unrestricted database or tool access.

Triage Agent

Wraps calibrated ML and deterministic rules.

classify_ticket · estimate_priority · explain_abstention

Context Agent

Builds the smallest authorized operational context.

requester_context · asset_context · ticket_history

Retrieval Agent

Finds, reranks and verifies approved evidence.

search_knowledge · similar_resolutions · verify_citations

Diagnosis Agent

Forms hypotheses and identifies missing information.

form_hypotheses · select_runbook · ask_clarification

Resolution Agent

Creates cited user and operator responses.

draft_response · resolution_plan · summarize

Governance Agent

Combines policy results into an execution decision.

assess_risk · check_policy · require_approval

Action Agent

Executes only signed, approved tool calls.

dry_run · execute · verify · rollback

Evaluation Agent

Scores offline traces and compares variants.

score_trace · compare_variants · failure_clusters

Leakage control

How the benchmark stays honest

Grouped splitsSplit synthetic data by generation version, not random rows.
Answers withheldNever put test answers into the OpenSearch knowledge index.
Frozen golden setBalance 300 manually reviewed tickets across queue, type and priority.
Immutable lineageRecord source hashes, transformations, seed and model version in MLflow.

Metrics that decide promotion

Classical MLMacro-F1, balanced accuracy, per-class recall, calibration and selective coverage.
RetrievalRecall@5, MRR@10, nDCG@10 and citation precision.
GenerationGroundedness, unsupported claims, citation correctness, acceptance and edit distance.
SafetyPII leakage, blocked unauthorized calls, unsafe actions and audit completeness.
Operationsp50/p95 latency, model calls, cache hits, CPU/GPU seconds, energy and retries.
Business pilotHuman minutes, response time, MTTR, FCR, reopen, SLA and CSAT from GLPI events.
